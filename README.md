# Retail Sales Performance Analysis Using Microsoft Excel

## Project Overview
This project focuses on analyzing retail sales data using Microsoft Excel. I completed this project independently in just **40 minutes**, without following any tutorials.

The main objective was to transform raw sales data into meaningful business insights and support data-driven business decisions.

## Project Tasks
- Converted raw data into an Excel Table.
- Cleaned and formatted customer names.
- Checked missing values and duplicate records.
- Calculated Gross Sales.
- Calculated Discount Amount.
- Calculated Net Sales.
- Analyzed key performance indicators (KPIs).
- Created PivotTables for regional and product analysis.
- Compared sales performance across regions.
- Analyzed sales contribution by region.
- Evaluated profit margins and Return on Investment (ROI).
- Made business recommendations based on the analysis.

## Key Business Analysis
- Compared regional sales performance.
- Identified high-performing and low-performing regions.
- Compared profit margins between regions.
- Evaluated investment opportunities using ROI.
- Used business insights to support investment decisions.
